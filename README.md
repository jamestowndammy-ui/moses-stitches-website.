# Moses Stitches Website

A responsive, static website for Moses Stitches, a tailoring and fashion business in Lagos, Nigeria. It is designed for hosting on GitHub Pages.

## Included files

- `index.html` — website content and sections
- `styles.css` — visual design and responsive/mobile layout
- `script.js` — mobile navigation and automatic footer year
- `README.md` — these instructions

## Before publishing

1. Check the WhatsApp number and business address in `index.html`.
2. Replace the sample fashion photography with photos of actual Moses Stitches garments when available. The current photos are illustrative remote images and require an internet connection.
3. You can edit the website text in `index.html` and colours/layout in `styles.css`.

## Publish using GitHub Pages

1. Sign in at https://github.com/
2. Create a **public** repository named `moses-stitches-website`.
3. Upload the four files from this folder to the **root** of the repository. Make sure `index.html` is not inside another nested folder.
4. Open the repository's **Settings** tab.
5. Select **Pages** in the sidebar.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch `main` and folder `/(root)`, then click **Save**.
8. Wait a few minutes and refresh the Pages section. GitHub will show your published website URL, usually `https://YOUR-USERNAME.github.io/moses-stitches-website/`.

- This is a static website; it does not require a database, server, passwords, or API keys.
- Google Fonts and the sample image URLs load from external services, so they require an internet connection.
